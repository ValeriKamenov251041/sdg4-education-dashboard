# SDG 4 education dashboard

An interactive Power BI dashboard that tracks progress on UN Sustainable Development Goal 4
(quality education), built for policymakers, researchers and the public.

Individual project by Valeri Kamenov, Applied Data Science & AI, Breda University of Applied
Sciences, Year 1 Block A (September to October 2025).

## Data

- European Social Survey, rounds 9, 10 and 11 (cleaned, joined and modelled in Power BI)
- A UN SDG 4 indicator (gender parity in education)
